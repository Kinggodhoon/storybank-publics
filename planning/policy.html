03 / Episodes

에피소드 정책

분할 · 버전 · 요약과 발췌

  • EP-1분할 기준원고 본문의 시작·끝 문단 번호로 에피소드 범위 확정. 다른 에피소드의 승인 범위나 검토 중인 범위와 겹치면 거절.
  • EP-2버전수정·범위 조정은 새 버전으로 추가. 승인된 버전은 한 번에 하나이며, 새 버전 승인 시 이전 승인 버전은 대체됨. 반려 시 승인 버전 유지.
  • EP-3승인 요약관리자가 승인한 요약만 공개(U6 기본안). AI가 만든 요약도 관리자 검수 전에는 확정하지 않음.
  • EP-4공개 발췌그 에피소드 원문에 그대로 있는 문장만 허용(저장 시 일치 확인). 발췌 공개 동의가 있을 때만 게시.
  • EP-5실명 금지요약·발췌·원고 소개에 사람 이름 사용 금지(작성 기준, 관리자 화면 안내). 본문의 실명·제3자 정보는 가림(RT-5)으로 처리하고, 민감정보 검수를 통과해야 공개 목록에 오름.
  • EP-6제외관리자가 사유를 남기고 에피소드를 제외하면 공개 목록과 판매에서 빠짐. 이미 구매한 회원은 구매한 버전을 계속 읽음.
  • EP-7게시 중단권리 문제로 관리자가 사유를 남기고 게시를 중단하면 공개 목록·판매·유료 열람에서 빠지고, 이미 구매한 회원도 전문을 읽을 수 없음(서재에 "게시가 중단된 에피소드" 표시). 관리자가 중단한 것만 개별로 재개하고, 원고 철회로 중단된 것은 재개하지 않으며, 동의서 파기로 중단된 것은 새 동의서를 확인한 뒤 원고 단위로 한 번에 재개.

2차 창작판매 판정과 무관동의서 범위—(U2와 함께 결정)
  • RT-1동의서 확인관리자가 내용을 확인한 뒤 확인 처리(파일 열람은 기록됨). 확인 전 동의서는 판정에 쓰지 않음.
  • RT-2보관 기한보관 기한(한국 날짜)이 지난 동의서는 증빙에서 제외. 요약 공개 범위가 사라지면 공개 목록에서 내리고(등재 대기), 회차 판매 범위만 사라지면 판매 차단.
  • RT-3간이 계약"저작권은 작가, 출판권은 레페토" 조건의 계약을 시스템에서 생성(계약 주체 명칭 확인 필요). 전자서명 없이 동의서(회원 업로드는 업로드 동의)로 증빙. 발급할 때 권리 기록·증빙·승인 에피소드·조항 문구를 그대로 저장해, PDF는 언제 받아도 같은 내용. 원고마다 발급 계약은 하나이고, 바꾸려면 무효로 한 뒤 다시 발급. 원고 철회나 증빙 동의서 파기 시 무효. 계약 번호는 SC-YYMMDD-NNNN.
  • RT-4승인 게이트원문 일치 → 민감정보·제3자 → 권리자 공개 승인의 3단계 검수(권리자 승인은 관리자가 확인 방법과 함께 기록, U6). 앞 단계가 통과여야 다음 단계를 통과로 정할 수 있고, 불통과와 권리자 승인에는 메모가 필요. 앞 단계를 불통과로 바꾸면 뒤 단계 결정은 되돌림. 결정은 지우지 않고 이력으로 남김. 공개 목록에 오른 에피소드의 새 버전은 3단계를 통과해야 승인하며, 그 전까지 이전 승인 버전이 그대로 공개됨.
  • RT-5가림본문의 개인정보·제3자 정보·명예훼손 우려 부분을 문단 번호와 글로 지정해 가림(이 등장만·이 문단 전체·원고 전체). 구매자 전문에는 ■■로 표시. 공개 발췌에 가린 글이 있으면 민감정보 검수를 통과할 수 없음. 발췌와 겹치는 가림을 더하거나 범위에 걸친 가림을 지우면 해당 버전의 민감정보·권리자 승인 검수를 다시 받음.
  • RT-6동의서 파기기한이 지났거나 잘못 올린 동의서는 사유를 남기고 파기(파일 삭제, 파기 사실과 사유는 보관). 판매 근거가 된 동의서는 마지막 판매 뒤 5년 동안 파기할 수 없음. 관리자 등록 원고가 판매 범위 증빙을 모두 잃으면 에피소드 게시를 중단하고 간이 계약을 무효로 함.
  • RT-7권리자 연락처권리자 이메일·전화번호는 관리자가 "연락처 보기"를 누를 때만 표시되고 열람 기록이 남음. 권리자 확인과 공개 승인, 계약 안내에만 사용.

공개 목록에 오르는 조건

  • LS-1승인승인된 버전이 있고, 에피소드가 제외·게시 중단되지 않았으며, 원고가 공개 상태(반려·취소·철회 아님).
  • LS-2외부 공개현재 권리 기록이 있고 외부 공개가 허용됨.
  • LS-3익명화익명화가 필요한 원고는 가림을 마치고 민감정보 검수를 통과해야 함(LS-5에 포함).
  • LS-4요약 공개 동의요약 공개 범위의 증빙이 있음(동의서 또는 업로드 동의).
  • LS-5승인 게이트원문 일치·민감정보·권리자 공개 승인 3단계를 통과함(RT-4).

판매 상태 판정 순서

위에서부터 먼저 맞는 상태로 결정. 원고·에피소드·상품·권리·동의서·업로드 동의가 바뀌면 해당 원고의 판정과 공개 목록을 즉시 다시 계산.

06 / Orders

주문·열람 정책

장바구니 · 주문 · 취소 · 전문 열람

  • OD-1장바구니유료 회원만 이용. 한 번에 50개, 장바구니 전체 100개까지. 구매 가능한 회차만 담기.
  • OD-2주문장바구니에서 지금 구매할 수 있는 회차를 한 주문으로 생성(구매할 수 없는 회차는 표시 후 제외). 이미 구매했거나 결제 대기 중인 회차는 거절. 주문 시점의 가격·제목과 구매한 버전을 보관.
  • OD-3중복 주문 방지같은 제출을 여러 번 보내도 주문은 하나. 결제 확인 대기 주문은 회원당 5개까지.
  • OD-4주문 번호SB-YYMMDD-NNNN 형식, 날짜별 일련번호.
  • OD-5결제 확인관리자가 입금 확인 후 처리(U1 결정 전 기본안). 확인 시 회차별 판매 가능 여부를 다시 확인하고, 판매할 수 없는 회차가 있으면 확인을 거절하고 관리자가 주문 취소.
  • OD-6취소결제 확인 전에만 가능. 구매자는 자기 주문, 관리자는 모든 대기 주문(사유 기록). 결제 완료 후 환불은 이번 범위 밖.
  • OD-7이용 범위전문 열람과 비상업 참고. 상업적 활용은 건별 협의(U2).

07 / Settlement

정산·지급 정책

  • ST-1배분저작권자 몫 = 회차 판매 금액 × 배분율(기본 70%, 설정값, U16)을 원 단위 내림. 나머지는 플랫폼 몫.
  • ST-2생성 시점결제 확인과 같은 처리에서 회차마다 이용 기록(UE-…)과 정산 내역 생성. 배분율은 이때의 값을 복사해 이후 설정이 바뀌어도 유지.
  • ST-3지급 기록관리자가 저작권자의 미지급 정산 내역을 묶어 지급일·방법 메모와 함께 기록. 같은 내역은 한 번만 지급 처리.
  • ST-4송금실제 송금은 시스템 밖에서 처리하고 지급 사실만 기록. 자동 송금은 이번 범위 밖.

예시. 25,000원 회차 1건 결제 확인 → 저작권자 몫 17,500원, 플랫폼 몫 7,500원의 정산 내역 생성.

08 / Operations

운영·보안 정책

관리자 권한 · 기록 · 파일

  • OP-1관리자 접근관리자 등급 계정만 관리자 화면 접근. 그 밖의 계정은 404 표시. 관리자도 회원과 같은 로그인 화면 사용.
  • OP-2관리자 보호자기 계정의 등급·상태 변경 불가. 마지막 활성 관리자는 강등·비활성·탈퇴 불가.
  • OP-3최근 로그인 확인탈퇴, 관리자 등급 부여, 관리자 계정 재활성화, 비밀번호 저장은 10분 이내 로그인한 세션에서만 가능.
  • OP-4열람 기록전문, 원고 본문, 원본 파일, 동의서, 회원 정보, 권리자 연락처, 간이 계약 PDF 열람 시 열람자·시각·대상 기록.
  • OP-5파일 제공원본·동의서는 열람 기록을 남긴 뒤 60초 유효 링크로만 제공. 등록 후 바뀐 파일은 열지 않고 알림.
  • OP-6감사 로그등급·상태·승인·권리·가격·주문·지급 변경을 수정·삭제할 수 없는 기록으로 저장. 관리자 화면에서 조회.

정식 공개 전 추가 조건. 보안 강화 조치, 외부 메일 발송(SMTP), 약관·개인정보 처리방침 법무 검토.
